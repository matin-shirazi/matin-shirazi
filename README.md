### Hi, I'm Mohammadreza (Matin) Shirazi

MSc in Management Information Systems, working on **Trustworthy AI** and **LLM-agent security**.
My current focus is how we *measure* prompt-injection defenses for tool-using LLM agents, and how evaluation choices can change the conclusions we draw from the same runs.

**Research interests:** LLM security · prompt injection · AI agents · AI safety & governance · Human–AI interaction

#### Current work

| Project | What it is |
|---|---|
| [**AdaptiGuard**](https://github.com/matin-shirazi/Adapti-guard) | Empirical case study of measurement validity in LLM-agent defense evaluation: success endpoint, blocked-payload labeling, scenario validity, per-model reporting and noise floor. Frozen traces, offline reproduction script, number-ledger check. Manuscript in preparation. |
| [**agent-injection-bench**](https://github.com/matin-shirazi/agent-injection-bench) | Small, honest benchmark for indirect prompt injection leading to tool misuse in agent / RAG settings. Paired D0–D2 pilot; every reported number is tied to a `run_id` and traces. |

#### How I work

- Claims scoped to the evidence: negative and null results are reported, not hidden
- Every number in a paper traceable to a committed artifact
